## PiSAs

The scenario files are preserved from the supplied snapshot. Replay projections and catalog metadata are generated by AOS Collaboration. Source hashes and dataset provenance are recorded in `data/manifest.json` and the replay records. Recorded evaluations were produced using upstream PiSAs code revision `1a47ea461f1f78f2b7a87e38d351e4ebc7380fbd`.

CLI replication includes evaluator annotations for the 39 selected cases from the same dataset revision, with their source hashes in `data/replication.json`. Eight native execution and evaluation modules are vendored unchanged under `aos/collaboration/replication/vendor/pisas/` from PiSAs code revision `1a47ea461f1f78f2b7a87e38d351e4ebc7380fbd`; their identities are recorded in `SOURCE.json`. The supplied PiSAs code snapshot did not include its own license file. The dataset's Apache 2.0 attribution is not a separate license grant for that source code.

Runtime dependencies are installed separately and retain their own distribution licenses.
